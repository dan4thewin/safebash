## Direct value and status

`$(mkdtemp)` is a nullary string intrinsic. It reuses the existing
`SsaValue::CmdSubst` carrier and direct intrinsic lowering, not a subprocess,
stdout capture or new IR representation. Both backends call
`sash_mkdtemp(checked, out_len, out_status)` and retain its actual status.
Ordinary checking aborts inside the runtime before the source assignment;
an untyped capture-condition disables that check, binds this attempt's value
and consumes its status. An inner `-` discards only the status.

Canonical intrinsic recognition supplies the source clean classification.
SSA cleanliness and the terminal walk's NUL-free fact are independently
wired. Neither a clean replacement nor a NUL proof resolves an existing
binding's unresolved taint. ERR creation requires a writable destination
and actual handling of the creation failure.

Arity, sole-value placement, string typing, typed-condition refusal,
discarded-status refusal and operand/body checking remain separate.
Both backend malformed-carrier matrices now include an extra-argument
constructor. Those direct checks failed before their nullary assertions and
pass afterward; source malformed calls retain SB4045.
No new unit-test function, diagnostic code or artifact schema is introduced.

## Exclusive creation and failure state

The implementation uses public rustix `getrandom` and `mkdirat`.
A fixed `/tmp/sash.` prefix and 16 random bytes rendered as 32 lowercase
hexadecimal digits form the pathname. Up to 128 attempts retry EEXIST;
directories, regular files and symlinks are never adopted. Short entropy
reads are completed, EINTR is retried, and zero progress becomes EIO.
There is no environment-derived template or fallback directory.

The randomness source, suffix format, attempt bound and private ABI are
AI implementation choices, not additional language constants selected by DG.
The settled contract is fixed `/tmp`, exclusive owner-only creation,
restricted generated bytes and a direct clean/NUL-free result.

The runtime reserves the terminated 43-byte result **before** entropy or
creation. Heap exhaustion therefore cannot create a directory whose name
the caller never receives. On success the stable result contains the
42-byte pathname and status 0. On a handled recoverable error, the
reservation is freed and the result is a nonnull terminated empty string
with status 1, never the previous pathname or successful empty output.
Ordinary failure reports its errno and enters the existing abort path.

DD130 classifies the operation, cause and resulting state, not an errno
without context. Returned entropy and `mkdirat` errors are contained failed
attempts: no descriptor, child or successful pathname has been published;
partial entropy is discarded and the reservation is freed. The specs
include syscall ENOMEM for both paths. Runtime heap exhaustion remains
fatal, including beneath handling/discard, and precedes those syscalls.
This constructor-local classification does not settle the remaining
file-I/O inventory or make every occurrence of ENOMEM recoverable.
